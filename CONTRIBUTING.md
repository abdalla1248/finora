## ⚡ Quick Contribution Steps

1. **Find or Open an Issue**: Check existing issues or open a new one following our [Issue Templates](.github/ISSUE_TEMPLATE/).
2. **Branch from `main`**: Name your branch using conventional prefixes (`feat/`, `fix/`, `docs/`, `refactor/`).
3. **Write Code & Tests**: Maintain 80%+ test coverage and adhere strictly to Feature-First architecture.
4. **Submit a Pull Request**: Fill out the [Pull Request Template](.github/PULL_REQUEST_TEMPLATE.md).
5. **Pass Quality Gates**: Ensure all linting, unit tests, and review approvals pass before merge.
