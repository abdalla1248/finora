## [1.0.0] - 2026-08-03

### Added
- **Core Architecture & Sprint 0**: Initialized production Flutter foundation with Feature-First MVVM architecture, GetIt DI container, GoRouter navigation, Material 3 design system, and 256-bit AES encrypted Hive storage.
- **Onboarding & User Module (Sprint 1)**: User profile creation, preferred currency selection, theme mode toggling, and splash screen initialization.
- **Transaction Engine (Sprint 2)**: Transaction CRUD operations, instant search, category filtering, date sorting, and transaction detail views.
- **Analytics & Dashboard (Sprint 3)**: Expense breakdown charts (`fl_chart`), net cash flow trends, savings rate ratio calculations, and deterministic financial insights.
- **Budget & Savings Goals (Sprint 4)**: Monthly/weekly budget targets with dynamic alert threshold badges (Green, Yellow, Red, Exceeded), target deadline countdowns, and dashboard active budget previews.
- **Accounts, Categories & Backup (Sprint 5)**: Multi-account balance management, custom expense/income category customization, searchable settings, JSON database backups, CSV exports, and factory reset functionality.
- **Release Readiness & CI Pipeline (Sprint 6)**: Added GitHub Actions CI pipeline, E2E integration test suite, release verification checklist, and complete production documentation.
